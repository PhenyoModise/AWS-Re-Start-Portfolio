_**Step 2: Create the python script**_
-	Open the Linux terminal and create a new Python file using a nano text editor.
-	Type the command to create a file called **prime_numbers.py**. This file will keep the Python code needed to calculate prime numbers. 
-	Once the file is created and opened, write the Python code that checks numbers from 1 to 250 and determines which numbers are prime

----
-	**Prime number: a number greater than 1 that can only be divided by 1 and itself.**
-----
-	Save the script and exit the editor. The script is made to automatically create a file called **results.txt**. 
-	The prime numbers generated will be written into this file. This ensures that the output is saved and can be accessed later without running the script again.


------

_**Step 3: Run the python script**_

Execute the script using Python 3. This is done by running the script below:

&nbsp;
**python 3 prime_numbers.py**. 

Running the script leads Python to execute the code, calculate the prime numbers between 1 and 250, and display them on the terminal screen.
