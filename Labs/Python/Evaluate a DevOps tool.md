_**Jenkins**_

Jenkins is an open-source automation server used mainly for Continuous Integration (CI) and Continuous Delivery/Deployment (CD) in software development.
In other terms, Jenkins automates repetitive development tasks such as building code, running tests, and deploying applications.

-----
**The purpose of Jenkins:**
1. Developers constantly change code. Jenkins automatically checks those changes and runs processes such as:
- Build the application: Compiles the code when developers push updates.
- Run automated tests: Ensures new code does not break existing functionality.
- Detect errors early: Sends alerts if a build fails.
- Deploy applications: Can automatically deploy to servers, cloud platforms, or containers.

-----
**_Why Companies Use Jenkins_**

Organizations use Jenkins because:

  - It automates development workflows
  - It reduces human errors
  - Detects bugs faster
  - Speeds up software releases
  - Supports huge ecosystems

_Companies using Jenkins include large tech teams and enterprises._

---

**_Jenkins – Common Use Cases_**

Jenkins is mainly used to automate parts of the software development lifecycle. Below are the most common real-world use cases.

_1. Continuous Integration (CI)_

Developers push code to repositories such as:

-	GitHub
-	GitLab

Jenkins automatically:
- Pulls the new code
- Builds the project
- Runs automated tests
- Reports if the build passed or failed

 _2. Continuous Delivery / Continuous Deployment (CD)_

Jenkins can automatically deploy applications after testing.

Typical deployment targets:
- Amazon Web Services
- Kubernetes
- Docker
- On-premise servers

_3. Automated Testing_

Jenkins can run different types of tests automatically:

- Unit tests
- Integration tests
- UI tests
- Performance tests

_4.Infrastructure Automation_

Jenkins can automate infrastructure provisioning and configuration.

It integrates with tools like:
- Terraform
- Ansible
  
----
Example tools Jenkins integrates with:
- Selenium
- JUnit

Every time code changes → Jenkins runs 1000+ automated tests.
If tests fail, developers are notified immediately.
